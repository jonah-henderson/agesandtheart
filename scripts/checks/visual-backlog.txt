# NOT a drive-server script. `scripts/drive-server.sh` writes to a throwaway world, so an Age it creates is
# not one you can walk. Paste these into a **client** chat (`./gradlew :fabric:runClient`).
#
# What each is FOR is written above it, and each says WHAT A WALK HAS TO SETTLE — that sentence is the
# acceptance test, not "does it look all right". Every line is deliberately seeded so what you see is what
# the next person sees; `/age list` prints a seed and a recipe, and pasting a printed composition back into
# `/age compose` rebuilds it exactly.
#

# Keep it that way. The last list rotted partly because it accumulated plausible-looking lines nobody had
# run — `climate.temperature=frigid` (that slot takes a numeric range), `phenomena=blizzard` (silently

# than no line, because it reads as the feature being broken.

# ══ 10. THE VOLCANIC CONES HAVE NEVER BEEN SEEN ══════════════════════════════ Built 2026-09-06 ══
# Step one of the volcanoes: the recipe entry and the shape. The cones generate; nothing is in them yet.
#
# **SHAPE IS JUDGED BY EYE, NOT BY A CHECK** (Jonah, 2026-09-06). These are meant to be organic and noisy
# rather than cookie-cutter, so pinning them with assertions buys flaky tests and an incentive to make the
# generation more regular than it should be. A shape check written for this was deleted the same day.
#
/age compose volc 11 landmass=hills sea=water rock=solid sky=plain features.grows=agesandtheart:volcano
/age tp volc
#
# **SEED 11 IS DRAWN OFFLINE TOO.** `./gradlew :common:preview --args=volcano` renders this same Age's
# nearest cone and prints where it stands (622, -269 -- floor around y=117); `--args=volcanoes` is the wide
# view. A cone is placed from the recipe seed unchanged, so the pictures and the walk are the same
# mountains, and looking at a shape no longer costs a flight. `scripts/checks/volcano.txt` drives the
# functional half.
#
# ── WHAT THE SECOND WALK CHANGED (2026-09-06) ────────────────────────────────────────────────────────
# Reported: still extremely pointed; the caldera had one block in the middle and no findable tubes;
# still far too regular; bombs too weak and too samey; impact lava left hanging in mid-air.
#
#   - **The caldera bottomed out at a point because the cut was an inverted CONE.** Its tip *is* one block.
#     It is now a truncated cone -- walls aimed to reach full depth exactly where a flat floor begins -- so
#     a crater is 40 to 60 blocks across at the rim with a real floor to stand a vent in.
#   - **The peak is truncated too**, or there is nothing to cut a crater into: a cone is one block wide
#     where the crater wants to be, and a bowl cut there only decapitates the mountain.
#   - **The profile is two cones now, steep over shallow**, which is what makes a flank concave and stops
#     the whole thing reading as a spike. The apron costs a lot of radius -- a cone based 100 blocks under
#     the ground shows only its last tenth -- and that radius is what the per-column cost is paid in.
#   - **The roughening had never worked.** A wavelength is `scale x 2^-firstOctave`, so `scale = 90` at
#     octave -5 is a swing 2,880 blocks across laid over a 300-block mountain: a constant, and a constant
#     shift only MOVES a cone. Fixed, and joined by `Warped`, a new toolkit node that displaces the query
#     column instead of its height -- the only thing here that reaches a silhouette, because undulating
#     something steep barely moves its outline.
#   - **One vent per crater, not one per chunk.** Every chunk of a caldera could see a bowl, so one volcano
#     had twenty masses and 95 bombs in the air at once. Now about four.
#   - **Bombs draw a bearing, a climb and a speed separately**, so a volcano spreads its fire instead of
#     shelling one ring: the flat fast shots carry seven or eight chunks, the steep slow ones fall back
#     into the crater.
#   - **Impact lava pours from the crater FLOOR upward**, one to three layers deep drawn per bomb, and a
#     bomb that finds no floor beneath it pools nothing.
#   - Lava tubes are **netherite-only and silk-touch-only**. Also fixed while there: the three temperstones
#     and the tube all carried `requiresCorrectToolForDrops` with no `mineable/pickaxe` entry, which means
#     they had been dropping NOTHING with any tool since they were written.
#
# ── WHAT THE THIRD WALK CHANGED (2026-09-06) ─────────────────────────────────────────────────────────
# Reported: "they definitely look like volcanoes now" -- but so massive they posed no credible threat, the
# bombs never coming near the rim; and the impact lava was STILL hanging in mid-air.
#
#   - **EVERYTHING IS HALF THE SIZE.** Nothing about the shape changed. A crater 30 across and 15 deep is
#     one a bomb thrown off the floor clears; 60 and 30 was not.
#   - A mountain is now authored in what anybody can SEE -- rise, foot, plateau above a nominal ground --
#     and the cones are solved from those, so rescaling is halving numbers that mean something.
#   - The shield lost its skirt: halving a volcano *widens* the radius a flat apron costs, and the squat
#     shape is gentle enough over its own flank not to want one.
#   - **BOMBS PLACE NO LAVA THEMSELVES ANY MORE.** An impact throws 3-12 gobbets which fall like sand and
#     turn to lava sources where they land -- Jonah's design, and the point is that nothing has to model
#     what the explosion did. The old code searched for the crater floor on the tick the blast moved it,
#     which is why lava kept ending up in the air.
#   - Stray vents in ordinary hill basins are now ACCEPTED rather than guarded against, which is what lets
#     the vent search sit low enough for the shield to erupt at all.
#
# WHAT THIS WALK HAS TO SETTLE, most of it dial-turning rather than pass/fail:
#   - **IS HALF THE RIGHT AMOUNT?** Roughly 33 blocks of relief over an 84-block visible radius for the
#     broad cone, 44 over 72 for the steep one, 22 over 98 for the shield. Height was called "about right"
#     at ~65 two walks ago, so if they now read as hills, RISE is the dial and it can move without the
#     footprint following.
#   - **DO THE BOMBS THREATEN ANYTHING NOW?** That is the whole reason for the resize: they should clear
#     the rim often, and being three or four chunks away should not be safety.
#   - **THE GOBBETS.** Does an impact leave a pool that looks like it belongs in the crater? Are 3-12 too
#     few to read, or so many the ground turns to lava? Do they splash convincingly down a slope?
#   - **IS THE WARP STILL RIGHT AT THIS SIZE?** It was halved with everything else. Past a gradient of
#     about 1 it folds and reads a second rim inside the crater; if you see that, it is too much.
#   - Spacing was NOT changed -- cells stay 580 apart, so half-size mountains sit relatively further from
#     each other. Judge whether volcanic country still reads as country.
#   - Does the caldera look like somewhere you would climb into, and can you find the vent once the lake
#     has covered it?
#   - **CALDERA LAKES: the vent was sitting ON the threshold that sizes a lake, and sometimes fell under.**
#     A crater's vent is a disc filtered by how far each column sits off the floor, so its mass is a DRAW:
#     a radius-two disc two deep is 26 nominal and a rumpled floor could cut it under the 16 that buys a
#     full pool -- so the caldera filled a patch of its own crater ("regularly failing to fill the bottom
#     level"). The disc is always radius three now and the floor filter admits three blocks of relief.
#     Measured 69 tubes / 1932 lake -> 87 / 2876, with wild vents unchanged at 177. **Judge whether the
#     lake now reaches the crater walls everywhere, and whether 2876 is too much lava rather than too
#     little** -- the mass also got deeper, so the pool rises higher than it used to.
#   - **A SMALL VENT NOW MAKES A SMALL POOL.** Reach is the vent's size squared, saturating at the throwing
#     threshold, so a nine-tube seam exposed on a hillside fell from ~1800 source blocks to 177 while
#     calderas kept everything. Judge whether a seam you dig into gives a satisfying amount of lava.
#   - **WHAT IS LEFT AT AN EDGE IS VANILLA'S FLOW, NOT OURS.** Measured on an isolated vent: 49 sources
#     placed (exactly right) and 672 further blocks of *flowing* lava pouring off the edge. A source always
#     spreads to its neighbours, so no rule about placement can stop it -- the pool keeps a block back from
#     a lip, which is not the same as stopping the spill. **If curtains of lava down a cliff still read as
#     wrong, the only remaining lever is a dry margin of lava's full flow reach (4 blocks, 8 in an
#     ultrawarm Age) from every drop**, which is a real cost and should be a decision rather than a tweak.
#   - **THE CALDERA ARRIVES WITH LAVA IN IT** -- ONE course over the vent, laid at generation. It was two
#     levelled courses and that stacked three or four deep on the low columns of a rumpled floor, which
#     with a gap beside them read as lava pillars. One course is held by its own tube whatever the
#     neighbours do. Judge whether one still reads as "this has been here a while".
#   - **THE BURIED CLUSTERS -- THE ONE REAL ITEM LEFT, AND NOTHING HAS SEEN IT.** Built and shipped; only
#     the count has ever been measured (5 tube blocks per chunk between y=-60 and y=60, plus rarer nests at
#     1-in-6 chunks). They are INERT until something opens the rock over them, so they cannot be walked by
#     standing anywhere -- you have to dig one out.
#     **HOW TO FIND ONE: WALK A CAVE.** Carvers run before decoration and the ore pass does not discard
#     air-exposed blocks, so tubes turn up in cave walls, floors and ceilings -- and they emit light 6, so
#     in a dark cave they announce themselves. Note the difference while you are down there: a tube in a
#     WALL or CEILING still has rock above it, so it is plugged and inert and only glows, while one in a
#     cave FLOOR has air above and is live, welling a small pool into the cave. Strip mining works too;
#     five tube blocks per chunk over a 120-block band is findable but slower.
#     WHAT IT HAS TO SETTLE:
#       * Are they findable while mining ordinarily, or only if you go looking? Too common, too rare?
#       * **A SEAM you open should give a puddle** -- 4 to 7 tubes buys a pool of about four blocks' reach.
#       * **A NEST is the one that could be nasty.** Thirty tubes is over the throwing threshold AND over
#         the point where reach saturates, so opening one in a tunnel means a full-size lake filling the
#         space you made and bombs starting up in it. Exciting, or does it just end the mine?
#       * Does an undersea one do anything worth doing, or is it only an obsidian farm?
#   - **CAN YOU TRACK A BOMB?** Gravity is a snowball's on purpose; the counterplay is looking up, reading
#     where one lands, and moving. Judged good last walk; confirm it survived the resize.
#   - That a bomb landing IN lava is inert -- the bound on the whole mechanic. If it still explodes there,
#     an Age drifts toward being made of lava.
#   - Whether a full 64-mass at explosion strength 7 is exciting or merely unplayable near a base.
#   - Does the blend turn two overlapping skirts into one massif, or leave a crease?
#   - LOW PRIORITY, DEFERRED BY JONAH 2026-09-06: that PLUGGING works -- a solid block over a tube stops
#     the welling, and lava over it does NOT count. Expected to work; walk it whenever.

# ══ 13. THE ASTRITE LURE, AND STORMS THAT ARE NOT CONSTANT ═══════════════════ Built 2026-09-07 ══
# **STORMS ARE TWENTY MINUTES APART NOW, NOT THIRTY SECONDS.** The old formula put an ordinary claim at
# six times its own written base and nobody had read it that way. So the first thing to check is simply
# that a meteoric Age feels like weather rather than a siege -- and that a rung still buys more:
#
/age write shower 11 meteors phenomena age
/age write teeming 11 teeming meteors phenomena age
#     -- ordinary waits ~20 min, teeming ~10, and 4x claims ~5. /age meteors still forces one on demand.
#
# **THE LURE.** Astrite blocks at or above Y=288 become lures. Build a cluster up there, then wait (or
# force a storm) and see where it falls:
/give @s agesandtheart:astrite_block 27
#   - A lure block should look different when placed high (budding amethyst stands in). Below 288 it
#     should look and do nothing.
#   - **THE RINGS ARE DRAWN ABOUT THE CLUSTER, NOT ABOUT EACH BLOCK** -- three horizontal rings of violet
#     dust on the centroid, on different clocks and sizes, some running out and some in, and WIDER for a
#     cluster that draws harder (2.6 blocks at one, 6 at twenty-seven). Eight blocks should be ONE set of
#     rings, not eight overlapping ones. Placeholder particles; a proper asset is owed.
#   - **A LURED STORM STANDS A COLUMN UP FOR THE WHOLE STORM.** The same dust goes up about eight blocks
#     and frays out at the top. Its height IS the cast's own strength, so it rises with the warning light,
#     stands full while the bodies come down, and sinks away as the violet goes out -- one curve read
#     twice rather than two clocks to keep in step. **WATCH FOR IT FROM THE GROUND**, which is who it is
#     for; it is forced past the 32-block particle cull for that reason.
#   - **DOES THE STORM COME TO IT?** It should centre on the cluster rather than on a bearing off you.
#   - **AND TIGHTEN.** EVERY ONE OF THESE IS A RADIUS -- 135 with no lure is 270 blocks of ground across,
#     90 for one block is 180, and the floor of 8 at twenty-seven or more is ONE CHUNK across.
#   - **THE VIOLET CAST NARROWS WITH IT.** A drawn storm lights the chunk it falls in and no more, so at
#     the floor you should be able to walk in and out of the warning in a couple of seconds. It used to

# 8a. THE SPIRE SHOULD BE PERMANENTLY DUSK, WITH ITS STARS ALWAYS OUT.
# It has no sun, so a day/night cycle buys it nothing. Wanted: stars visible at ALL times, light EVEN
# across the cycle at roughly dusk intensity, and time still PROGRESSING so the stars rotate. Today it is
# on the overworld's clock and goes properly dark and properly bright.
# THE LEAD, and the one real unknown: `star_angle` and `star_brightness` come from the SAME timeline
# (`#minecraft:in_overworld`), so rotation and fading cannot be separated by dropping the timeline — that
# would freeze the stars, which is the opposite of what is wanted. Settle first whether a constant
# `EnvironmentAttributeMap` entry on `age_spire.json` OVERRIDES a timeline track or is merely another layer
# under it (`EnvironmentAttributeSystem.bakeLayerSampler`). If it overrides, this is data only: pin
# `star_brightness` and the light attributes and leave `star_angle` to the timeline. If it does not, the
# painter has to stop reading vanilla's `starBrightness` for an Age that says so — which probably means
# `StarField` carrying its own constant brightness and `StarReveal` going away rather than being widened.
#
# 8b. THE WARM/COOL STAR AXIS IS TOO SUBTLE TO SEE.
# `WARM_STAR` (0.95, 0.87, 0.76) and `COOL_STAR` (0.78, 0.85, 1.0) are both nearly white, so the variation
# reads as noise rather than as colour. Push both toward saturation.
# WORTH KNOWING BEFORE TURNING THAT DIAL: the tint is `WARM.lerp(COOL, random.nextFloat())`, and a uniform
# draw puts most stars in the MIDDLE of the axis — neutral — however far apart the ends are. Biasing the
# draw toward the ends will do at least as much as widening it, and probably more.
