# The danger evaluator: does the table load off a real resource stack, and does `/age danger score` answer?
# Run with: scripts/drive-server.sh scripts/checks/danger.txt
#
# **Both risks here are ones the offline checks structurally cannot reach.** `DangerCheck` scores against a
# table it writes itself, and `DangerTableCheck` reads the shipped file through `MinecraftRegistries
# .shippedData()` — neither goes through `ResourceManager.getResourceStack` on a booted server, which is the
# call that actually has to find `art/danger.json`, and neither builds the Brigadier tree at all. A branch
# that fails to register throws at server start; a table that fails to load reports every Age at nought.
#
# **If every Age reads 0.000 the table did not load**, and nothing in the reward economy can ever pay. That
# is the one failure this file exists to catch, and it looks like success everywhere else.
#
# Note the sentences: an aiming page **closes** the clause it belongs to. `age inferno phenomena` writes an
# inferno; `age phenomena inferno` reads as a book with nothing aimed and is repaired into a whole random
# Age, which is a fine way to think you have found a bug in the scoring.

# The floor: an Age nobody said anything dangerous about.
age compose quiet 11 landmass=hills sea=water rock=solid sky=plain
age danger score quiet

# What the Age is made of, over the whole of it, and then over half of it — the averaging rule on real
# recipes. Read the two together: the same lava, half the ground, half the materials score.
age compose alllava 11 landmass=hills sea=lava rock=solid sky=plain
age danger score alllava
age compose halflava 11 landmass=hills sea=lava,water rock=solid sky=plain
age danger score halflava

# What lives here, and what happens here.
age write teeming 11 age teeming ghast spawns
age danger score teeming
age write burning 11 age inferno phenomena
age danger score burning

# A written Age over a template that brings its own lava and its own roof — the claim that a template needs
# no special case, because what it supplied is merged into the composition before the recipe holds it.
age write hellish 11 infernal age
age danger score hellish

# **The price, which fails silently and can fail no other way.** Deretheni is a word, but one that demands
# masterwork ink (`requires_masterwork_ink`, 2026-09-06). The tag is empty offline, so only a bound registry
# can show it, which is here. Expect pitchstone lines in the corpus.
age words json

# The deposit itself. Generate the hellish Age, then count what is actually in the ground: `fill ... replace`
# reports how many it changed, which is the only block census a vanilla server has. The quiet Age is the
# control -- it is under the threshold, so it must come back with nothing at all.
# `alllava` and `quiet` are the pair to read: the same landform over the same window, differing only in
# what they are made of, so the deposit is the only thing that can differ. `hellish` is no good for this --
# the infernal template floors at y=0, above the band a deposit is sited in.
#
# One chunk over the WHOLE deposit band (-56..39 is 96 levels; 16x16x96 = 24576, under fill's 32768 cap).
# Counting a partial band is how you talk yourself into thinking this is broken: the triangle peaks near
# y=-8, so a band that misses the peak reports a tenth of what is there.
#
# Measured 2026-09-05 at score 0.350: **4 blocks in one chunk**, against a nominal 2 veins x 4. The rest is
# carved away or overlaps itself, which is what vanilla's own ore veins do. `quiet` must report nothing.
age gen alllava
age gen quiet
execute in agesandtheart:alllava run forceload add 0 0 15 15
execute in agesandtheart:quiet run forceload add 0 0 15 15
execute in agesandtheart:alllava run fill 0 -56 0 15 39 15 minecraft:air replace agesandtheart:pitchstone_ore
execute in agesandtheart:alllava run fill 0 -56 0 15 39 15 minecraft:air replace agesandtheart:deepslate_pitchstone_ore
execute in agesandtheart:quiet run fill 0 -56 0 15 39 15 minecraft:air replace agesandtheart:pitchstone_ore

# And the structured form, which is what a check would assert on.
age danger json score hellish

# The raid (§7.7): a doomed Age is stuffed, and its hoard sits in the band the tear takes. `unstable=` sets
# the index *before the Age opens*, which is the only moment anything reaching generation can be steered —
# `/age decay` rewrites a recipe that is already open and so never reaches the deposit.
# Measured 2026-09-05: 3794 against 0 in the same band.
age compose doomed 11 unstable=400 landmass=hills sea=lava rock=solid sky=plain
age danger score doomed
age gen doomed
execute in agesandtheart:doomed run forceload add 0 0 15 15
execute in agesandtheart:doomed run fill 0 -62 0 15 -40 15 minecraft:air replace agesandtheart:pitchstone_ore
execute in agesandtheart:alllava run fill 0 -62 0 15 -40 15 minecraft:air replace agesandtheart:pitchstone_ore
