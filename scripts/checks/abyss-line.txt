# The abyss stays under its line: no deep water above it anywhere, and a vent's whirlpool that carries on
# through ordinary water to the surface. Run with: scripts/drive-server.sh scripts/checks/abyss-line.txt
#
# What it guards (walk list W7). Deep water under the ordinary sea used to run vanilla's bubble-column routine
# on its scheduled ticks with nothing under it to raise a column, and that routine's fall-through "occupies"
# every source above with the liquid itself -- a pump, carrying deep water up to the surface for the sea's
# settling to take back. And a real whirlpool, raised the same way, climbed to the surface as deep water.
#
# Seed 7 at (2000, 2000), as in deep-sea-vent.txt: floor y=29, sea level 134 with its top water block at 133,
# so the abyss line is 53 -- deep water from 29 to 53, ordinary from 54 up, as `age probe` shows.
# The counts run with random ticks off and `strict`, so a fill that takes away what it counts wakes nothing:
# without it, taking the whirlpool out above the line put air over the three blocks below it, and they
# settled ordinary before the next count read them.
age write lineage 7 age insular landmass deep water sea
age probe lineage 2000 2000
execute in agesandtheart:lineage run forceload add 1984 1984 2015 2015
execute in agesandtheart:lineage run place feature agesandtheart:deep_sea_vent 2000 40 2000
# Random ticks are what woke the pump: the abyss's top layer settling, and the sea's answer to it. The
# fillers are what the driver's wait is for -- see deep-sea-vent.txt on why `tick sprint` cannot be used.
gamerule random_tick_speed 2000
age list
age list
age list
age list
age list
age list
age list
age list
gamerule random_tick_speed 0
# Deep water above the line: MUST read zero in every quadrant. 16 x 16 x 81 each, under the fill limit.
execute in agesandtheart:lineage run fill 1984 54 1984 1999 134 1999 minecraft:air replace agesandtheart:deep_water strict
execute in agesandtheart:lineage run fill 2000 54 1984 2015 134 1999 minecraft:air replace agesandtheart:deep_water strict
execute in agesandtheart:lineage run fill 1984 54 2000 1999 134 2015 minecraft:air replace agesandtheart:deep_water strict
execute in agesandtheart:lineage run fill 2000 54 2000 2015 134 2015 minecraft:air replace agesandtheart:deep_water strict
# The whirlpool above the line: none of it deep, and some of it there at all if it reaches the surface.
execute in agesandtheart:lineage run fill 1992 54 1992 2008 134 2008 minecraft:air replace agesandtheart:deep_bubble_column[deep=true] strict
execute in agesandtheart:lineage run fill 1992 54 1992 2008 134 2008 minecraft:air replace agesandtheart:deep_bubble_column[deep=false] strict
# And below it, the abyss's own: deep, and the vent's chamber and bore full of it -- MUST read no ordinary.
execute in agesandtheart:lineage run fill 1992 15 1992 2008 53 2008 minecraft:air replace agesandtheart:deep_bubble_column[deep=true] strict
execute in agesandtheart:lineage run fill 1992 15 1992 2008 53 2008 minecraft:air replace agesandtheart:deep_bubble_column[deep=false] strict
