# The aiming pages, the quantifier production, and the readout that shows both.
# Run with: scripts/drive-server.sh scripts/checks/quantifiers.txt
#
# Server-side because the words this is about are DERIVED — biomes and structure sets come from the
# dynamic registries, so `villages` and `jungle` do not exist in the offline corpus at all.
#
# Read the output rather than trusting an exit code: this drives a server, it does not assert. What
# should pass or fail lives in `WritingCheck`.
#
# EVERY SENTENCE HERE OPENS WITH `age`, AND HAS TO. The nucleus is mandatory, so a book without one is
# not a sentence and is filled in against one the Art draws for itself — which keeps the writer's content
# pages and drops the structural ones, `only` and the rungs among them. A sentence that loses its nucleus
# does not fail here; it quietly starts showing what repair does instead.

# --- The readout ---------------------------------------------------------------------------------
# The whole point of the prose is that it shows where each page landed. Two aiming pages, two sections,
# and each material must come back under the part it was written against.
# Expect: `landmass floating of basalt, over sea molten of lava.` and nothing under `supplied`.
age write readsback age landmass floating basalt sea molten lava

# The same content words with no aiming page in front of them are the nucleus, and the readout has to
# say so rather than inventing a division nobody wrote.
# Expect: `floating of basalt.`
age write unaimed age floating basalt

# A page the Art never heard of is a typo, not a vague book — a page is a physical item carrying a real
# word, so an unknown one cannot have been written.
# Expect: the command refuses by name and writes no Age.
age write laundered age landmass zzzznotaword basalt

# --- The quantifier ------------------------------------------------------------------------------
# `teeming villages` is what the production exists for. The rung must reach the recipe on the claim,
# spelled with the `@` mark.
# Expect: `structures.built=minecraft:villages@teeming`, and `villages` at density `teeming` under `said`.
age write manyvillages age structures teeming villages

# Expect: `structures.built=minecraft:villages@scarce`.
age write fewvillages age structures scarce villages

# A rung binds to ONE term. Joined with another value, only the quantified one carries it.
# Expect: `minecraft:woodland_mansions,minecraft:villages@teeming` — the mansions bare of any rung.
age write onlyoneteems age structures woodland_mansions and teeming villages

# `only` and a rung on the same value — the two axes are independent and must not eat each other.
# Expect: `structures.built=!minecraft:villages@teeming`, polarity `only` and density `teeming`.
age write onlyteeming age structures only teeming villages

# --- The knobs no word could reach ---------------------------------------------------------------
# Each was pinned into a recipe and unreachable from a sentence.
# Expect: `mingling=fine`.
age write finemingle age landmass finely basalt and slate

# Expect: `biomes.skin=bare`.
age write bareskin age biomes bare

# --- What the writer sees ------------------------------------------------------------------------
age list
