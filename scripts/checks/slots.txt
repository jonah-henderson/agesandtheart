# Phase 2 acceptance: combinations nobody hand-wrote should generate, and the composer should refuse
# only what it cannot read. Run with: scripts/drive-server.sh scripts/checks/slots.txt
#
# Read the output rather than trusting an exit code — this drives a server, it does not assert. What
# to look for is noted against each group.

# --- The two combinations the implementation plan names by name -------------------------------
# Spire islands over real water rather than plasma, and hills with something going on underneath.
age compose spireocean landform=spire_islands medium=sea subsurface=weathered dressing=bare_rock sky=storm
age compose hillcaves landform=hills medium=sea subsurface=flooded_caves dressing=overworld sky=storm

# --- Others nobody wrote, to stress the slot list ---------------------------------------------
age compose lavapillar landform=pillars medium=lava subsurface=solid dressing=verdant sky=plain
age compose deepcavern landform=caverns medium=sea medium.depth=deep subsurface=porous dressing=plasma sky=plain

# A landform that stands in open air, told to have a sea anyway. The landform's contract must win:
# expect it to be created and to generate dry, not to crash.
age compose drypyramid landform=pyramids landform.arrangement=rings medium=sea sky=storm

# An option no preset understands. Expect it kept, ignored, and reported by /age list below —
# never silently dropped, because the recipe is the only record of an Age.
age compose typoage landform=shapes landform.elevation=towering

# --- What the composer must refuse, naming the alternatives ------------------------------------
# Expect "An Age needs a landform" and "No landform called 'atlantis'. Try: ..." — and no Age.
age compose nolandform medium=sea
age compose nonsense landform=atlantis

# --- Do they actually build? -------------------------------------------------------------------
# Surface heights and blocks, not pictures. Looking right is still a job for a human in game.
age gen spireocean
age gen hillcaves
age gen lavapillar
age gen deepcavern
age gen drypyramid
age gen typoage

# --- Same sentence, same seed, twice -----------------------------------------------------------
# Expect "identical: 25 chunks agree block for block" for both pairs. Note both use a non-decorating
# dressing on purpose: with dressing=overworld, vanilla's decoration pass differs from itself and
# swamps the answer (see the reproducibility measurement in notes/).
age compose bareA 777 landform=eroded medium=sea subsurface=caves dressing=bare_rock sky=plain
age compose bareB 777 landform=eroded medium=sea subsurface=caves dressing=bare_rock sky=plain
age compare bareA bareB 2

age compose spireA 777 landform=spire_islands medium=sea subsurface=weathered dressing=plasma sky=storm
age compose spireB 777 landform=spire_islands medium=sea subsurface=weathered dressing=plasma sky=storm
age compare spireA spireB 2

# --- What got written --------------------------------------------------------------------------
# Every line here should be pasteable straight back into /age compose, and typoage should carry its
# "(ignored, unrecognised: landform.elevation)". Run this file twice against the same --level to
# check the same sentences come back after a restart.
age list
