# Phase 2 acceptance: combinations nobody hand-wrote should generate, and the composer should refuse
# only what it cannot read. Run with: scripts/drive-server.sh scripts/checks/aspects.txt
#
# Read the output rather than trusting an exit code — this drives a server, it does not assert. What
# to look for is noted against each group.
#
# **REPAIRED 2026-09-16, and it had been composing almost nothing.** Six lines used the old `depths=` slot,
# which is now `rock=` — see `Aspect.CARVERS`, which says why: a carver runs wherever there is stone to
# cut, where `underground=` is a place built beneath it. Since `drive-server.sh` asserts nothing and exits
# 0 either way, those six Ages had been refused in silence for as long as the slot has been split.
#
# **Two of the repairs are substitutions rather than translations**, and should be read as somebody's
# guess at the intent:
#
#   - `depths=weathered` on `spireocean` named a preset that no longer exists; `Carvers` is now exactly
#     solid, porous, caves and flooded_caves. It says `rock=flooded_caves`, which keeps a wet subsurface
#     under the spires, but nothing says that is what `weathered` meant.
#   - `sea.depth=deep` on `deepcavern` was never valid *and was never failing loudly*: `Sea.DEPTH` is a
#     ranged parameter, so `deep` parsed as an unrecognised option, was kept, and was reported — meaning
#     that Age has been generating an ordinary sea all along, since well before the `depths=` breakage.
#     It now says `0.9..1.0`, near the top of an axis whose far end is "96 blocks up".
#
# Driven 2026-09-16 after the repair: all fourteen Ages compose. The refusals still refuse, naming the
# alternatives; `typoage` still comes back carrying "(ignored, unrecognised: landmass.elevation)", which is
# the point of it; `bareA`/`bareB` differ by 10 blocks over 2 of 25 chunks, the small non-zero the note
# below predicts; and `spireX`/`spireY` are still identical across 25 chunks.
#
# Every Age here now also carries `underground=noise_caves`, which is `AgeComposition`'s own default rather
# than anything this file asked for — the other half of what `depths=` used to conflate.

# --- The two combinations the implementation plan names by name -------------------------------
# Spire islands over real water rather than plasma, and hills with something going on underneath.
age compose spireocean landmass=spire_islands sea=water rock=flooded_caves sky=storm
age compose hillcaves landmass=hills sea=water rock=flooded_caves sky=storm structures=vanilla

# --- Others nobody wrote, to stress the aspect list ---------------------------------------------
age compose lavapillar landmass=pillars sea=lava rock=solid sky=plain
age compose deepcavern landmass=hills sea=water sea.depth=0.9..1.0 rock=porous underground=tunnels sky=plain

# A terrain that stands in open air, told to have a sea anyway. The terrain's contract must win:
# expect it to be created and to generate dry, not to crash.
age compose drypyramid landmass=pyramids landmass.arrangement=rings sea=water sky=storm

# An option no preset understands. Expect it kept, ignored, and reported by /age list below —
# never silently dropped, because the recipe is the only record of an Age.
age compose typoage landmass=hills landmass.elevation=towering

# --- Structures as a population: add, emphasise, exclude ----------------------------------------
# Values are structure *sets*. `!` is only, `-` is except, `@rung` is density (see Claim and Density).
# Expect all three to survive /age list verbatim. What a smoke test cannot assert is what actually got
# built, so confirm with /locate — dimension ids are lower-cased, and the position argument is required:
#   execute in agesandtheart:onlymansions positioned 0.0 100.0 0.0 run locate structure minecraft:village_plains
# expecting "Could not find"; and minecraft:mansion expecting a hit.
age compose onlymansions landmass=hills sea=water structures=vanilla structures.built=!minecraft:woodland_mansions
age compose nooutposts landmass=hills sea=water structures=vanilla structures.built=-minecraft:pillager_outposts
# Density: four times the villages. Expect the nearest village markedly closer than in `nooutposts`.
age compose teemingvillages landmass=hills sea=water structures=vanilla structures.built=minecraft:villages@teeming
# Our own halves of nether_complexes, reachable only because the biome is named too. Expect a fortress
# and NO bastion_remnant — the split is the whole reason those two files exist.
age compose fortsonly landmass=hills sea=water structures=none structures.built=agesandtheart:fortresses biomes.grown=minecraft:crimson_forest

# --- What the composer must refuse, naming the alternatives ------------------------------------
# Expect "An Age needs a terrain" and "No landmass called 'atlantis'. Try: ..." — and no Age. (The slot is
# said `landmass` in both messages; `terrain` is the aspect's own name and never reaches a writer.)
age compose nolandform sea=water
age compose nonsense landmass=atlantis

# --- Do they actually build? -------------------------------------------------------------------
# Surface heights and blocks, not pictures. Looking right is still a job for a human in game.
age gen spireocean
age gen hillcaves
age gen lavapillar
age gen deepcavern
age gen drypyramid
age gen typoage

# --- Same sentence, same seed, twice -----------------------------------------------------------
# **Rewritten 2026-07-29, and the old expectation is why.** This used to expect "identical: 25 chunks agree
# block for block", and it got that by naming a deliberately non-decorating dressing (`bare_rock`, `plasma`).
# Those presets are deleted, so every composed Age now wears vanilla's biome table and *decorates* — and
# decoration does not reproduce block for block (design 6.5, measured). Expecting zero here would fail
# forever, for a reason that is not a bug.
#
# So read a small count rather than zero, and read it against a control the way generator-parity.txt says
# to. That file carries the measured per-Age control band; this is the same method at a smaller radius.
age compose bareA 777 landmass=eroded sea=water rock=caves sky=plain
age compose bareB 777 landmass=eroded sea=water rock=caves sky=plain
age compare bareA bareB 2

# The one true zero left in the mod: a bespoke Tier-B generator on a biome of its own, which decorates
# nothing vanilla gets to choose. If THIS is ever non-zero, something really did move.
age create spire spireX 777
age create spire spireY 777
age compare spireX spireY 2

# --- What got written --------------------------------------------------------------------------
# Every line here should be pasteable straight back into /age compose, and typoage should carry its
# "(ignored, unrecognised: landmass.elevation)". Run this file twice against the same --level to
# check the same sentences come back after a restart.
age list
