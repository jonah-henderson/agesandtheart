# Does uncut ground exist? — the one number that says whether generator version 11 did anything.
# Run with: scripts/drive-server.sh scripts/checks/uncut-ground.txt
#
# Under the plain union, `solid` carried no carvers and so was the union's *identity*: it could not lose an
# argument, it simply vanished. Measured then, `riddled` against `riddled unbroken` differed by **two
# blocks, and both of them were water** — the water coming from hydrology, which already divided.
#
# A carvers that cuts nothing anywhere now holds a territory in which no walk starts, so the second
# sentence should differ from the first over a large share of its caves. Same seed throughout, so nothing
# but the carvers can be responsible for a difference.
#
# **REPAIRED 2026-09-16.** All three lines used the old `depths=` slot, now `rock=`, so none of these Ages
# had been composing at all — and `drive-server.sh` asserts nothing and exits 0 either way, so the file
# reported nothing wrong while measuring nothing. The `#?` bounds went too: that layer is gone and such
# lines are skipped outright, having read the first integer on the matching line, which on a server log is
# the hour off the timestamp. Both numbers below are read by eye now.
#
# Every Age here also carries `underground=noise_caves` now, which is `AgeComposition`'s default rather
# than anything this file asked for. It does not touch the measurement: both sides of each comparison get
# the same underground, so the difference still isolates the carvers, which is the whole question.

# Caves throughout, and caves against uncut ground. `compose` rather than `write` so the carvers is
# stated outright and no resolver draw can quietly seat a third preset.
#
# The recorded numbers below were measured with `dressing=overworld`, which the dressing's deletion removed
# from these lines (2026-07-29). Both Ages now decorate, which puts a small non-zero floor under every
# comparison here — irrelevant at this scale, since the signal is ~249,000 blocks against a floor in the
# tens, but worth knowing before reading the control pair as exact.
age compose riddledonly 7 landmass=gentle sea=minecraft:water rock=caves
age compose riddledsolid 7 landmass=gentle sea=minecraft:water rock=caves,solid

# THE NUMBER. Two blocks means the union is still swallowing `solid`; a large count means uncut ground
# exists. Expect the difference to be air-versus-stone rather than water, which is what tells uncut ground
# apart from the hydrology division that was already there.
#
# MEASURED 2026-07-27, generator version 11: **248,734 blocks over 284 of 289 chunks** at radius 8 (and
# 174,329 over all 169 at the radius 6 used below, re-measured 2026-07-30), against
# two under the plain union. Uncut ground exists.
#
# RE-MEASURED 2026-09-16, the first run since the file was repaired: **101,976 over 141 of 169** at radius
# 6. Lower than the 174,329 recorded above and over fewer chunks, which is worth knowing before reading
# that figure as current — everything under `rock=` and the underground has moved since July. The finding
# is unchanged and is the only thing this number is for: some fifty thousand times the two blocks the
# plain union gave, so `solid` is holding ground of its own.
#
# The bound is the *regression* it guards against rather than the measurement: two blocks was the old
# behaviour, and anything in that neighbourhood means `solid` is being swallowed again. Six orders of
# magnitude sit between the two readings, so a loose floor loses nothing and survives retuning.
# WAS `#? at-least 10000 block(s) differ`. The `#?` layer is gone and such lines are now skipped outright
# (CLAUDE.md): it read the first integer on the matching line, which on a real server log is the hour off
# the timestamp, so this could never have passed. Read the count below against ten thousand by eye.
age compare riddledonly riddledsolid 6

# And the control: two carvers that both *cut* must still union, so this pair should differ from
# `riddledonly` by whatever porosity adds, not by territory.
#
# MEASURED: 65,779 blocks over 73 of 169 chunks at radius 6 — porosity's scattered vugs added on top of the
# caves, in the chunks it reached. The union between two cutting carvers is untouched. (Re-measured
# 2026-07-30 while these expectations were being written: 67,138 over 68 of 169. Same reading.)
# (Re-measured 2026-09-16 after the repair: 60,134 over 71 of 169. Same reading again, and well inside the
# band — nowhere near the uncut-ground count, so the two cutting carvers are still unioning.)
#
# Bounded on both sides, because this one is a control and both directions mean something. Nothing at all
# would say porosity stopped adding anything; a count up near the uncut-ground reading — 174,329 over all
# 169 chunks at this radius — would say the two cutting carvers had stopped unioning and started dividing
# territory, which is the bug next door. The ceiling sits between the two readings.
age compose riddledporous 7 landmass=gentle sea=minecraft:water rock=caves,porous
# WAS `#? at-least 1000` and `#? at-most 150000 block(s) differ`, and neither could fire — see the note
# above. Both bounds mean something here, so read the count by eye: below a thousand says porosity stopped
# adding anything, and up near 174,329 says the two cutting carvers began dividing territory instead.
age compare riddledonly riddledporous 6

age list

# 1,118 blocks, where `caves` against either differs by ~249,000. So this measures **suppression**, and only
# glances the seam. Whether the division reads well across a whole world is a walk, not a number.
